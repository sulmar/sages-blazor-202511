# 📋 Task: Product List Page

## 🧩 Goal:

Your task is to create a Blazor page that displays a tabular list of products retrieved from an API.  
The goal of this exercise is to practice fetching data from a service and presenting it in a table using Blazor syntax.

---

## ✅ Functional Requirements:

1. Create a Blazor page: `Pages/Products/List.razor`  
2. Display a table with a list of products on the page  
3. Each row should contain:
   - Product name  
   - Price (formatted as `123.45 EUR` or your local currency)  
   - Short description  

---

## 🧠 Extension (optional)

- Add a “Details” column with a link to the `Products/View.razor` page  
- Style the table (e.g., add headers, borders, margins)  


## ⏱️ Estimated Time: **30 minutes**
